# secure-auth-platform
A secure authentication platform with JWT, 2FA, role-based access control, password recovery, and PostgreSQL.



## Planned Features

- JWT-based authentication
- Access and refresh token management
- Two-factor authentication (2FA)
- Forgot and reset password
- Role-based access control (RBAC)
- Protected REST APIs
- PostgreSQL database
- Automated authentication tests

## Tech Stack

### Backend
- Node.js
- Express.js
- TypeScript
- PostgreSQL
- Prisma ORM

### Frontend
